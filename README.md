# Meme-Translation


برنامج يقرأ الكاميرا ويعرض **ميماً** فوق وجهك يطابق تعبيرك.

## كيف يعمل؟

1. يقرأ الكاميرا ويكتشف وجهك.
2. يقيس فمك وعينيك بالأرقام.
3. يقارن الأرقام بحدود وضعتُها، ويحدد التعبير (ابتسامة، قبلة، صدمة...).
4. يعرض الميم المناسب في منتصف وجهك.

## التشغيل

```bash
pip install opencv-python cvzone mediapipe
python face.py
```

اضغط **q** للخروج.

## الملفات

- `face.py`: البرنامج.
- `memes/`: صور الميمات.

## إضافة ميم جديد

1. ضع الصورة في مجلد `memes`.
2. أضفها إلى القاموس `memes` في `face.py`.
3. أضف شرطاً للتعبير الذي يناسبها.
